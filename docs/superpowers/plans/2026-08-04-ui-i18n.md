# UI Internationalization (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Translate molvi's entire user-facing UI (Settings window + dictation overlay + system-tray menu) into all 36 distinct Nemotron languages with a sidebar language picker, default English, instant switching.

**Architecture:** No i18n library — a plain static dictionary + `t(key)` lookup. Frontend (Settings + overlay) shares one TS dictionary (`src/i18n/`); the tray is Rust-side with its own small typed table (`tray_locales.rs`). `dir="rtl"` flip + CSS logical-property audit for the two RTL languages (ar, he). Language choice persists in `settings.ui_lang` (default `"en"`).

**Tech Stack:** Rust (edition 2024, rustc 1.97.1) + Tauri 2.11.5 backend; vanilla TypeScript 7 + Vite 8 frontend (no framework). Windows-only.

## Global Constraints

- **No new dependencies.** No i18n library. Plain `Record<string,string>` object + property-access lookup. No `i18next`, no ` Intl` polyfills.
- **No backward compat** (owner directive): `settings.ui_lang` is a clean new field; an old settings.json without it deserializes to `"en"` via the struct's `Default`. No migration, no version field.
- **Privacy §10.1 (HARD):** never log transcript/partials/audio. i18n is frontend + tray-menu text; the 82-test privacy suite (`src-tauri/tests/log_privacy.rs`) must stay green and is never edited by this plan.
- **RTL correctness (ar, he):** the only two RTL languages. `dir=rtl` flip on both webviews + CSS uses logical properties so the layout mirrors. Tray menu RTL is OS-handled.
- **Blaze (no regression):** RTF, cold-start, RSS, NSIS size unaffected. `locales.ts` ≈ 30 KB gzipped — negligible.
- **Ponytail:** smallest diff; reuse the existing `patcher`/`store`/section-builder pattern; the only new structural elements are `src/i18n/`, the pinned sidebar row, and `tray_locales.rs`.

- [ ] **Step 6: Create `src/i18n/index.ts` (registry + `t()` + RTL).**

```ts
// No i18n library: a property access is the fastest possible lookup.
// Anything else (i18next, lazy fetch) is slower. This is "maximally performant".
import type { Lang } from "./locales";
import { locales } from "./locales";

type LangEntry = { code: Lang; label: string }; // label = endonym (native name)

// ISO 639-1 sorted (owner requirement). Endonyms let users find their language
// in their own script — "better than competitors" who show English names only.
export const LANGUAGES: ReadonlyArray<LangEntry> = [
  { code: "ar", label: "العربية" }, { code: "bg", label: "Български" },
  { code: "cs", label: "Čeština" }, { code: "da", label: "Dansk" },
  { code: "de", label: "Deutsch" }, { code: "el", label: "Ελληνικά" },
  { code: "en", label: "English" }, { code: "es", label: "Español" },
  { code: "et", label: "Eesti" }, { code: "fi", label: "Suomi" },
  { code: "fr", label: "Français" }, { code: "he", label: "עברית" },
  { code: "hi", label: "हिन्दी" }, { code: "hr", label: "Hrvatski" },
  { code: "hu", label: "Magyar" }, { code: "it", label: "Italiano" },
  { code: "ja", label: "日本語" }, { code: "ko", label: "한국어" },
  { code: "lt", label: "Lietuvių" }, { code: "lv", label: "Latviešu" },
  { code: "mt", label: "Malti" }, { code: "nb", label: "Bokmål" },
  { code: "nl", label: "Nederlands" }, { code: "nn", label: "Nynorsk" },
  { code: "pl", label: "Polski" }, { code: "pt", label: "Português" },
  { code: "ro", label: "Română" }, { code: "ru", label: "Русский" },
  { code: "sk", label: "Slovenčina" }, { code: "sl", label: "Slovenščina" },
  { code: "sv", label: "Svenska" }, { code: "th", label: "ไทย" },
  { code: "tr", label: "Türkçe" }, { code: "uk", label: "Українська" },
  { code: "vi", label: "Tiếng Việt" }, { code: "zh", label: "中文" },
];

const RTL_LANGS: ReadonlySet<Lang> = new Set<Lang>(["ar", "he"]);

let current: Lang = "en";
export function getCurrentLang(): Lang {
  return current;
}

export function setCurrentLang(code: Lang): void {
  current = code;
  // The one-change RTL trigger: flex/grid + logical CSS mirror with dir=rtl.
  const rtl = RTL_LANGS.has(code);
  document.documentElement.dir = rtl ? "rtl" : "ltr";
  document.documentElement.lang = code;
}

// 3-level fallback: current → English → raw key (visible, never crashes).
export function t(key: string): string {
  return locales[current]?.[key] ?? locales.en[key] ?? key;
}
```

//! Tray-menu strings, Rust-side. The tray is built in Rust, so it has its own
//! small typed table (same 36 language codes as the frontend). Named struct →
//! every language carries every key (compile-checked): a missing field is a
//! build error.

pub struct TrayStrings {
    pub toggle: &'static str,
    pub settings: &'static str,
    pub history: &'static str,
    pub quit: &'static str,
    pub status_ready: &'static str,
    pub status_warming: &'static str,
    pub recording: &'static str, // tray icon tooltip while recording ("● molvi")
}

pub const TRAY_LOCALES: &[(&str, TrayStrings)] = &[
    ("en", TrayStrings {
        toggle: "Toggle mode", settings: "Settings", history: "History",
        quit: "Quit", status_ready: "molvi", status_warming: "molvi (warming up)",
        recording: "● molvi",
    }),
    ("ru", TrayStrings {
        toggle: "Режим переключения", settings: "Настройки", history: "История",
        quit: "Выход", status_ready: "molvi", status_warming: "molvi (запуск)",
        recording: "● molvi",
    }),
    // The other 34 languages are filled by the translation tasks (Tasks 9-12).
];

/// Linear scan (36 entries; the menu rebuilds only on language change) →
/// fallback to English for an unknown/missing code.
pub fn tray_t(lang: &str) -> &'static TrayStrings {
    TRAY_LOCALES
        .iter()
        .find(|(code, _)| *code == lang)
        .map(|(_, s)| s)
        .unwrap_or_else(|| {
            TRAY_LOCALES
                .iter()
                .find(|(code, _)| *code == "en")
                .map(|(_, s)| s)
                .expect("en entry always present")
        })
}

#[cfg(test)]
mod tests {

    }
    #[test]
    fn unknown_lang_falls_back_to_en() {
        assert_eq!(tray_t("xx").settings, "Settings");
    }
    #[test]
    fn en_entry_present() {
        assert_eq!(tray_t("en").quit, "Quit");
    }
}
