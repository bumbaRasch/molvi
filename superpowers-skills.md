# Superpowers Skills (14)

## Process / Thinking
- **brainstorming** — before any new feature/component. Explores intent & requirements.
- **systematic-debugging** — before any bugfix. Finds root cause, not symptom.
- **using-superpowers** — meta: when to invoke which skill.

## Planning & Execution
- **writing-plans** — spec → step-by-step plan, before code.
- **executing-plans** — run a written plan with review checkpoints.
- **subagent-driven-development** — implement plan via subagents in-session.
- **dispatching-parallel-agents** — 2+ independent tasks → parallel agents.

## Testing & Verification
- **test-driven-development** — TDD: test before implementation.
- **verification-before-completion** — no "done" until verification commands pass with proof.

## Code Review
- **requesting-code-review** — self-check before merge/commit.
- **receiving-code-review** — review feedback rigorously, don't agree blindly.

## Git / Integration
- **using-git-worktrees** — isolated workspace via git worktree.
- **finishing-a-development-branch** — what to do when code is green & ready.

## Meta
- **writing-skills** — create/edit your own skills with validation.
